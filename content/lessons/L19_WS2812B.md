# الدرس 19: WS2812B — معركة النانوثانية ⚡

> **المرجع:** WorldSemi WS2812B datasheet + تجربتك على logic analyzer.
> **العتاد:** CH32V003 + شريط WS2812B (يكفي LED واحد للتجربة) + مصدر تغذية مستقر 5V.
> **الشرط المُسبَق:** أكملت [L05 Clock System](/lessons/l05-clock-system) — يجب أن يعمل المتحكّم على **48 MHz** كي يحقّق التوقيت.

---

## 📋 تعريفات السجلات لهذا الدرس

انسخ هذا البلوك إلى رأس `main.c` قبل تشغيل أيّ مثال من هذا الدرس. الأمثلة في الأسفل تفترض أنّ هذه التعريفات موجودة.

```c
typedef unsigned int u32;

// ── RCC ──────────────────────────────────────────────
#define RCC_BASE    0x40021000
#define RCC_APB2PCENR   (*(volatile u32*)(RCC_BASE + 0x18))

// ── GPIOC ──────────────────────────────────────────────
#define GPIOC_BASE    0x40011000
#define GPIOC_BSHR      (*(volatile u32*)(GPIOC_BASE + 0x10))
#define GPIOC_BCR       (*(volatile u32*)(GPIOC_BASE + 0x14))
#define GPIOC_CFGLR     (*(volatile u32*)(GPIOC_BASE + 0x00))

// تأخير busy-loop بسيط (يكفي للأمثلة الأساسية)
static void delay(volatile u32 cycles) {
    while (cycles--) { __asm__ volatile ("nop"); }
}
```

> 💡 جميع العناوين مستخرجة من *CH32V003 RM v1.9*، الفصل الخاصّ بكل peripheral. الجدول مرتّب بترتيب الاستخدام في الدرس.

---


## 0. لماذا هذا الدرس مختلف؟

كل ما تعلّمناه حتى الآن كان عن **مساعدة العتاد** (UART, SPI, I2C — كلّها تملك peripheral داخل الشريحة يتولّى التوقيت). أمّا **WS2812B**، فلا يوجد peripheral مخصّص له. علينا أن نوقّت كل بِت يدوياً بدقّة **نانوثانية** عبر تعليمات `nop` محسوبة.

هذا ما يُسمّى **Bit-Banging** — قيادة الإشارة برمجياً بحتاً.

---

## 1. ما هو WS2812B؟

LED ذكيّ بثلاث ألوان (RGB) داخل غلاف 5×5mm، يحتوي على دائرة تحكّم. تُجمَع عشرات منها على شريط أو لوحة وتُتسلسل عبر سلكٍ واحد فقط لإشارة البيانات.

**المغريات:**
- ✅ سلك بيانات واحد لمئات الـ LEDs
- ✅ كل LED قابل للتلوّن باستقلال (24-bit color)
- ✅ زهيد (~$0.05 لكل LED)

**التحدّي:**
- ❌ بروتوكول غير قياسي — مملوك لـ WorldSemi
- ❌ توقيت حسّاس جداً (تحمّل ~150ns)
- ❌ لا peripheral عتادي يدعمه

---

## 2. البروتوكول — الوحدة الأساسية: البِت

كل بِت يُرسَل في فترة ثابتة قدرها **1.25 µs**، لكن نسبة HIGH/LOW داخلها تحدّد قيمته:

| البِت | High (T1H/T0H) | Low (T0L/T1L) | الإجمالي |
|------|----------------|----------------|------------|
| `1`  | **800 ns**     | 450 ns         | 1.25 µs |
| `0`  | **400 ns**     | 850 ns         | 1.25 µs |

ثم بين كل **frame** (إطار بيانات كامل) وآخر:
- **Reset signal**: ≥ 50 µs LOW

تحمّل الـ WS2812B الأصلي ±150 ns، لكن نسخه الحديثة (Clones) أحياناً تقبل ±300 ns. لا تعتمد على التساهل.

---

## 3. ترتيب الألوان — فخّ شائع

لكل LED ثلاث بايتات: **G, R, B بهذا الترتيب** (مش R,G,B!).
لكل لون 8 بِتات، **MSB-first** (أول بِت يُرسَل هو bit 7).

```c
// لتشغيل LED أحمر كامل:
uint8_t green = 0x00;
uint8_t red   = 0xFF;
uint8_t blue  = 0x00;
// ترسلها بالترتيب: green ثم red ثم blue (24 بِت إجمالاً)
```

> 💡 لو لاحظت أن "الأحمر" يصير "أخضر" — هذا هو الخطأ. تأكّد من ترتيب G-R-B.

---

## 4. حساب الـ nops على CH32V003 @ 48 MHz

سرعة التشغيل = 48 MHz = `48,000,000` دورة/ثانية → كل دورة = **20.833 ns**.

| التوقيت المطلوب | الدورات اللازمة |
|------------------|-------------------|
| 400 ns (T0H)     | 19.2 ≈ **19 nops** |
| 450 ns (T1L)     | 21.6 ≈ **22 nops** |
| 800 ns (T1H)     | 38.4 ≈ **38 nops** |
| 850 ns (T0L)     | 40.8 ≈ **41 nops** |

> ⚠️ هذا تقدير. كل `nop` نظرياً يأخذ دورة، لكن قد يتأثر بـ pipeline والـ flash wait state. **لا تثق بالحساب — قس بالـ logic analyzer**.

---

## 5. الكود — `send_bit` بـ inline assembly

> 💡 تعريفات `GPIOC_BSHR/BCR` موجودة في بلوك **📋 تعريفات السجلات** أعلى الصفحة.

```c
#define WS_PIN_MASK (1u << 1)              // PC1

#define WS_HIGH()  (GPIOC_BSHR = WS_PIN_MASK)
#define WS_LOW()   (GPIOC_BCR  = WS_PIN_MASK)

// macro يُنشِئ N تعليمات nop متتالية بـ inline assembly
#define NOP1   __asm__ volatile("nop")
#define NOP4   NOP1; NOP1; NOP1; NOP1
#define NOP8   NOP4; NOP4
#define NOP16  NOP8; NOP8
#define NOP32  NOP16; NOP16

static inline void send_1(void) {
    WS_HIGH();
    NOP32; NOP4; NOP1; NOP1;   // ~38 cycles → T1H ≈ 800 ns
    WS_LOW();
    NOP16; NOP4; NOP1; NOP1;   // ~22 cycles → T1L ≈ 450 ns
}

static inline void send_0(void) {
    WS_HIGH();
    NOP16; NOP1; NOP1; NOP1;   // ~19 cycles → T0H ≈ 400 ns
    WS_LOW();
    NOP32; NOP8; NOP1;         // ~41 cycles → T0L ≈ 850 ns
}

static inline void send_byte(uint8_t b) {
    for (int i = 7; i >= 0; i--) {
        if (b & (1 << i)) send_1();
        else              send_0();
    }
}
```

## 6. التعطيل الإجباري للمقاطعات

أيّ مقاطعة (SysTick, UART RX، …) تأخذ **عشرات الدورات** = تكسر التوقيت → LED يعرض ألواناً عشوائية.

**يجب** تعطيل المقاطعات أثناء إرسال الإطار:

```c
static inline void irq_disable(void) {
    __asm__ volatile ("csrci mstatus, 8");   // امسح بِت MIE
}
static inline void irq_enable(void) {
    __asm__ volatile ("csrsi mstatus, 8");   // اضبط بِت MIE
}
```

> 🔑 على RISC-V، `csrci mstatus, 8` تمسح بِت MIE (Machine Interrupt Enable) في سجل `mstatus`. هذا يكافئ `cli` في معماريات أخرى.

## 7. إرسال إطار كامل — RGB pixel واحد

```c
typedef struct { uint8_t r, g, b; } pixel_t;

void send_pixel(const pixel_t *p) {
    // GRB order — بهذا الترتيب
    send_byte(p->g);
    send_byte(p->r);
    send_byte(p->b);
}

void send_strip(const pixel_t *pixels, uint16_t count) {
    irq_disable();
    for (uint16_t i = 0; i < count; i++) {
        send_pixel(&pixels[i]);
    }
    irq_enable();
    // Reset signal بعد آخر بايت: pin يبقى LOW
    delay(60 * 8);     // ≥ 50 µs
}
```

## 8. مثال متكامل — Rainbow على LED واحد

```c
// … (الكود السابق فوق)

int main(void) {
    // HSI = 24 MHz بشكل افتراضي عند الإقلاع — لا حاجة لتهيئة هنا
    // ساعة 48 MHz لازمة! اقرأ L05.

    // PC1 = Output Push-Pull 50 MHz
    RCC_APB2PCENR |= (1u << 4)  /* IOPCEN */;
    GPIOC_CFGLR &= ~(0xF << (4 * 1));
    GPIOC_CFGLR |=  (0x3 << (4 * 1));

    pixel_t pixel = {0, 0, 0};

    while (1) {
        // أحمر
        pixel = (pixel_t){.r = 64, .g = 0,  .b = 0};
        send_strip(&pixel, 1);
        delay(500 * 8000);

        // أخضر
        pixel = (pixel_t){.r = 0,  .g = 64, .b = 0};
        send_strip(&pixel, 1);
        delay(500 * 8000);

        // أزرق
        pixel = (pixel_t){.r = 0,  .g = 0,  .b = 64};
        send_strip(&pixel, 1);
        delay(500 * 8000);
    }
}
```

> 💡 لاحظ أنّ السطوع 64/255 — لا تستعمل القيمة القصوى 255 إلّا لو الـ LED معزول حرارياً. على شريط طويل تتراكم الحرارة.

## 9. التحقّق بالـ logic analyzer

افتح أداة مثل **PulseView** أو **Saleae Logic** واربط الـ analyzer على PC1:

| ما تتوقّعه | معنى الانحراف |
|----------|---------------|
| نبضة 800 ns ± 100 لـ T1H | ✅ نطاق سليم |
| نبضة < 600 ns لـ T1H | ❌ زيادة nops |
| نبضة > 1000 ns لـ T1H | ❌ تقليل nops |
| LOW متفاوتة عشوائياً | مقاطعة لم تُعطَّل |

## 10. تحسينات متقدّمة

### Pattern: Send كامل قبل أي pixel

```c
void update_strip_async(uint8_t *buf, uint16_t bytes) {
    irq_disable();
    while (bytes--) send_byte(*buf++);
    irq_enable();
    // No need to Delay_Us — caller knows to wait ≥ 50us before next call.
}
```

### Pattern: Color wheel

```c
pixel_t color_wheel(uint8_t pos) {
    if (pos < 85)        return (pixel_t){pos*3,       255-pos*3,  0};
    else if (pos < 170)  return (pixel_t){255-(pos-85)*3, 0,       (pos-85)*3};
    else                 return (pixel_t){0,            (pos-170)*3, 255-(pos-170)*3};
}
```

### Brightness scaling

```c
pixel_t scale_brightness(pixel_t p, uint8_t bright) {
    return (pixel_t){
        .r = ((uint16_t)p.r * bright) / 255,
        .g = ((uint16_t)p.g * bright) / 255,
        .b = ((uint16_t)p.b * bright) / 255
    };
}
```

## 11. أخطاء شائعة

| العَرَض | السبب | الحل |
|---------|------|-------|
| لون "خربان" | ترتيب G-R-B لم يُتَّبَع | تأكّد من الترتيب |
| LEDs تتذبذب عشوائياً | مقاطعة تكسر التوقيت | `irq_disable()` |
| أوّل LED صح والباقي عشوائي | عدد nops غير دقيق | قس بالـ logic analyzer |
| لا شيء يضيء | المعالج على 24 MHz بدل 48 | راجع L05 (PLL init) |
| LED أوّل فقط يتأثّر | الـ reset غير كافٍ | كبّر `delay(60 * 8)` |
| ألوان "تطفر" أحياناً | تذبذب في 5V supply | استخدم capacitor 1000µF على الـ rail |
| LEDs بعيدة تخفّ | جهد ينخفض بطول الشريط | حقن طاقة وسط الشريط لكل ~10 LEDs |

## 12. تمارين

1. **Loopback timing**: أرسل بِت واحد فقط (`send_1` ثم Delay طويل)، وقس عرضه على logic analyzer. اضبط nops حتى يساوي 800 ns تماماً.
2. **8 LEDs strip**: أرسل لـ 8 LEDs متعاقبة كل واحد بلون مختلف.
3. **Rainbow scrolling**: استعمل `color_wheel` وحرّك الألوان عبر 16 LED بزمن.
4. **Brightness control via ADC**: اربط potentiometer على PC4 (ADC2). اقرأه، استعمله كـ brightness عام على كل الـ LEDs.
5. **Frame timing**: قس كم frame في الثانية يستطيع المتحكّم إرسال لـ 30 LED، 60 LED، 144 LED.
