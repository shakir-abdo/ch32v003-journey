# الدرس 05: نظام الساعة (Clock System) في CH32V003

> **النسخة v3 — مراجعة عتادية** | كل المعلومات مأخوذة من *CH32V003 Reference Manual* الفصل 3 (RCC).
> النسخة السابقة كانت تحوي أخطاءً جوهرية تم تصحيحها (انظر "تصحيحات هامة" في النهاية).

---

## مقدمة

نظام الساعة هو القلب النابض لأي متحكم دقيق. هو الذي يحدّد سرعة تنفيذ الأوامر، ويؤثر مباشرة على الأداء واستهلاك الطاقة. في الـ `CH32V003` فهم هذا النظام يعني فهم ثلاث طبقات:

1. **مصادر التوليد** — من أين تأتي إشارة الساعة؟
2. **التوزيع (Bus & Prescalers)** — كيف توزّع على الأطراف؟
3. **التحويل والمراقبة (Switching & CSS)** — كيف نغيّر المصدر بأمان؟

---

## 1. مصادر الساعة (Clock Sources)

شريحة `CH32V003` تملك **أربعة** مصادر/دوائر لتوليد الساعة:

| المصدر | التردد | المصدر | الاستخدام |
|--------|--------|--------|-----------|
| **HSI** (High-Speed Internal) | **24 MHz** ±1% | RC داخلي | المصدر الافتراضي بعد الـ Reset |
| **HSE** (High-Speed External) | **4–25 MHz** | كريستال خارجي | تطبيقات تحتاج دقة عالية |
| **LSI** (Low-Speed Internal) | **128 kHz** | RC داخلي منخفض السرعة | **IWDG فقط** + Low-Power wake-up |
| **PLL** | يضرب الدخل ×2 | دائرة مضاعفة | الوصول إلى 48 MHz |

### تفاصيل مهمة لكل مصدر

- **HSI = 24 MHz** (وليس 8 MHz). يعمل تلقائياً عند الـ Reset، وهو ما يشغّل الـ `main()` قبل أي إعداد. التحكم: بت `HSION` و علم `HSIRDY` في `RCC_CTLR`.

- **HSE**: يتطلب توصيل كريستال على OSC_IN/OSC_OUT. الميزة الأهم: دقة وثبات، ومحمي بنظام (CSS) يكشف إذا فشل الكريستال.

- **LSI = 128 kHz** (وليس 30 kHz). **مهم جداً**: لا يمكن استخدامه كمصدر للساعة الرئيسية (SYSCLK). وجهاته الوحيدة هي:
  - الـ Independent Watchdog (IWDG)
  - وحدة الـ PWR كمصدر منخفض الطاقة للوحدات في وضع Standby

- **PLL**: ليس مصدراً مستقلاً. يأخذ HSI أو HSE ويضرب التردد **×2 (ثابت — غير قابل للتعديل في CH32V003)**. اختيار المصدر عبر بت `PLLSRC` في `RCC_CFGR0`، والتشغيل عبر `PLLON` في `RCC_CTLR`.

> ⚠️ **حدّ السرعة الرسمي للنظام (SYSCLK) هو 48 MHz**. يتحقق فقط عبر `PLL × HSI(24) = 48 MHz` أو عبر `HSE 24MHz × PLL`.

## 2. شجرة الساعة (Clock Tree)

```
 HSI (24 MHz) ──┐
                ├──► [PLL ×2] ──► PLLCLK (48 MHz max)
 HSE (4-25 MHz)─┘                      │
                                       ▼
 HSI ──────────────────────► [SW MUX] ──► SYSCLK
 HSE ──────────────────────►    ▲
 PLL ──────────────────────►    │
                           SW[1:0] = 00/01/10
                                │
                                ▼
                             [HPRE] ──► HCLK ──► CPU + AHB
                                            ├──► APB1 (PCLK1)
                                            ├──► APB2 (PCLK2)
                                            └──► SysTick

 LSI (128 kHz) ──► IWDG + PWR (لا يدخل MUX النظام)
```

## 3. تهيئة 48 MHz — التسلسل الصحيح

الفكرة: عند الإقلاع نحن على HSI (24 MHz). نريد التحويل إلى `PLL = HSI×2 = 48 MHz`. التسلسل الذي يضمن استقرار النظام:

### الخطوة 1: تأكد أن HSI مستقر

في الواقع HSI شغّال افتراضياً، لكن من الأمان أن نضع البتات بأنفسنا:

```c
// تفعيل HSI (افتراضي شغّال، لكن للوضوح)
RCC_CTLR |= (1u << 0)  /* HSI on */;

// الانتظار حتى يستقر
while ((RCC_CTLR & (1u << 1)  /* HSI ready */) == 0);
```

### الخطوة 2: اختر مصدر PLL **قبل** تفعيله

في الـ `CH32V003` المضاعِف ثابت (×2)، لكن المصدر يُختار عبر `PLLSRC`:

```c
// مسح بت PLLSRC ثم ضبط HSI كمصدر للـ PLL
RCC_CFGR0 &= ~(1u << 16) /* PLL src bit */;     // 0 = HSI as PLL source
// إذا أردت HSE: RCC_CFGR0 |= (1u << 16) /* PLL src bit */;
```

> 💡 ملاحظة عن HSI/2: في عائلات WCH أخرى (CH32V103, CH32V20x) يوجد بت `HSIPRE` يقسم HSI/2 قبل PLL.
> في الـ **CH32V003 لا توجد قسمة قبل PLL**. الدخل يدخل كما هو ويتم ضربه ×2.

### الخطوة 3: شغّل PLL وانتظر استقراره

```c
RCC_CTLR |= (1u << 24) /* PLL on */;
while ((RCC_CTLR & (1u << 25) /* PLL ready */) == 0);
```

### الخطوة 4: ضبط ذاكرة الفلاش (Latency)

> ⚠️ خطوة كثيراً ما تُنسى ثم يتعطل النظام عند الانتقال إلى 48 MHz.

عند 48 MHz يجب إضافة Wait-State على الـ Flash:

```c
FLASH_ACTLR = (FLASH_ACTLR & ~(0x3u << 0)) | (0x1u << 0);
// LATENCY = 1 → wait state واحد للسرعات > 24 MHz
```

### الخطوة 5: حوّل ساعة النظام إلى PLL

```c
// مسح حقل SW ثم اختيار PLL
RCC_CFGR0 = (RCC_CFGR0 & ~(0x3u << 0)  /* SW field */) | (0x2u << 0)  /* SW=PLL */;

// انتظار التأكيد من العتاد عبر SWS (للقراءة فقط)
while ((RCC_CFGR0 & (0x3u << 2)  /* SWS field */) != (0x2u << 2)  /* SWS=PLL */);
```

> 🔍 الفرق بين `SW` و `SWS`:
> - `SW[1:0]` — نكتب فيه ما نريد (طلب).
> - `SWS[1:0]` — يكتبه العتاد عند نجاح التحويل (تأكيد).

---

## 4. حقل SW في RCC_CFGR0 — كل القيم الممكنة

| `SW[1:0]` | المصدر المختار | ملاحظة |
|-----------|-----------------|--------|
| `00` | HSI | الافتراضي بعد Reset |
| `01` | HSE | يجب أن يكون HSE Ready |
| `10` | PLL | يجب أن يكون PLL Ready |
| `11` | — | غير صالح (Not available) |

> ❌ **لا يوجد خيار LSI في SW**. أي محاولة لجعل LSI مصدراً للنظام عبر `RCC_CFGR0` ستفشل (الـ `while` على `SWS` سيدور للأبد).

## 5. المقسّمات (Prescalers) — صندوق التروس

بعد اختيار SYSCLK، يمر التيار عبر مقسّمات لتخفيض السرعة قبل توزيعها:

```
SYSCLK ──► HPRE ──► HCLK (CPU + AHB)
                       │
                       └──► APB peripherals
```

### حقل `HPRE[3:0]` في `RCC_CFGR0` (بتات 7:4)

| `HPRE` | القاسم | عند SYSCLK = 48 MHz | الاستخدام |
|--------|---------|---------------------|------------|
| `0xxx` | ÷1 | 48 MHz | الأداء الأقصى |
| `1000` | ÷2 | 24 MHz | تخفيض بسيط |
| `1001` | ÷4 | 12 MHz | — |
| `1010` | ÷8 | 6 MHz | — |
| `1011` | ÷16 | 3 MHz | — |
| `1100` | ÷64 | 750 kHz | توفير طاقة |
| `1101` | ÷128 | 375 kHz | منخفض جداً |
| `1110` | ÷256 | 187.5 kHz | — |
| `1111` | ÷512 | 93.75 kHz | الأبطأ — أقل استهلاك |

> 💡 إذا هدفك "تشغيل المعالج بأبطأ تردد ممكن"، الطريق الصحيح هو HSI + HPRE÷512 وليس LSI (لأن LSI لا يصل أصلاً إلى SYSCLK).

## 6. ساعات الأطراف (Peripheral Clocks)

كل طرف معطل افتراضياً لتوفير الطاقة. التفعيل عبر ثلاثة سجلات حسب الـ Bus:

| السجل | الـ Bus | أمثلة على الأطراف |
|------|---------|--------------------|
| `RCC_AHBPCENR` | AHB | DMA1, SRAM |
| `RCC_APB1PCENR` | APB1 | TIM2, USART2 (إن وُجد), I2C1, WWDG |
| `RCC_APB2PCENR` | APB2 | GPIOA/C/D, ADC1, TIM1, USART1, SPI1, AFIO |

مثال: تفعيل ساعة GPIOC (للـ LED):

```c
RCC_APB2PCENR |= (1u << 4)  /* IOPCEN */;
```

---

## 7. نظام الحماية CSS (Clock Security System)

ميزة مهمة لمن يستخدم HSE: إذا فشل الكريستال (انكسر، فقد التوصيل…)، يتحوّل النظام تلقائياً إلى HSI ويُرفع `CSSF`:

```c
RCC_CTLR |= (1u << 19);   // تفعيل المراقبة (بعد HSE Ready)
```

---

## 8. مخرج MCO (للتحقق بأوسيلوسكوب)

تستطيع إخراج إشارة الساعة على دبوس `PC4` للتأكد من أنك حصلت على التردد الصحيح:

```c
RCC_CFGR0 = (RCC_CFGR0 & ~RCC_CFGR0_MCO) | RCC_CFGR0_MCO_SYSCLK;
// 100: SYSCLK | 101: HSI | 110: HSE | 111: PLL
```

ثم اضبط PC4 كـ Alternate Function Push-Pull لرؤية الإشارة.

---

## 9. كسر السرعة (Overclocking) — الحقيقة

النسخة السابقة من هذا الدليل ادّعت أن PLL يضرب ×12 وبالتالي يمكن الوصول إلى 96 MHz. **هذا غير صحيح**.

الواقع في `CH32V003`:

- المضاعِف ثابت ×2 ولا يمكن تغييره.
- أعلى دخل HSE مسموح به (4–25 MHz). إذا أعطيت 25 MHz كحد أقصى، فإن `25 × 2 = 50 MHz` فقط.
- يبقى الحد الرسمي 48 MHz، وأي تجاوز بسيط يبقى ضمن هامش التصنيع لكن **غير مضمون عبر الشرائح**.

### المخاطر المحتملة (نفس مخاطر أي overclock)

- عدم استقرار في العمليات الحسابية والمنطقية.
- ارتفاع حرارة المعالج وانخفاض عمر الشريحة.
- فشل الأطراف عالية الاعتماد على التوقيت (UART, SPI, ADC).

> ⚠️ تجربة على مسؤوليتك. لا تستخدم في منتج تجاري.

## 10. مثال متكامل: من HSI إلى 48 MHz

```c
void SystemClock_48MHz_Init(void) {
    // 1) HSI ON + Ready
    RCC_CTLR |= (1u << 0)  /* HSI on */;
    while (!(RCC_CTLR & (1u << 1)  /* HSI ready */));

    // 2) اختيار مصدر PLL = HSI
    RCC_CFGR0 &= ~(1u << 16) /* PLL src bit */;

    // 3) PLL ON + Ready
    RCC_CTLR |= (1u << 24) /* PLL on */;
    while (!(RCC_CTLR & (1u << 25) /* PLL ready */));

    // 4) Flash latency = 1 wait state للسرعات > 24 MHz
    FLASH_ACTLR = (FLASH_ACTLR & ~(0x3u << 0)) | (0x1u << 0);

    // 5) HPRE = ÷1 (نريد الأداء الكامل)
    RCC_CFGR0 &= ~(0xFu << 4)  /* HPRE field */;

    // 6) تحويل SYSCLK إلى PLL
    RCC_CFGR0 = (RCC_CFGR0 & ~(0x3u << 0)  /* SW field */) | (0x2u << 0)  /* SW=PLL */;
    while ((RCC_CFGR0 & (0x3u << 2)  /* SWS field */) != (0x2u << 2)  /* SWS=PLL */);
}
```

| الادعاء القديم | الواقع (من Reference Manual) |
|-----------------|------------------------------|
| HSI = **8 MHz** | HSI = **24 MHz** |
| LSI ≈ **30 kHz** | LSI = **128 kHz** |
| PLL يضاعف **×12** | PLL يضاعف **×2 (ثابت)** |
| يجب قسمة HSI على 2 قبل PLL | لا توجد قسمة في CH32V003 |
| Overclock 96 MHz ممكن | لا — الحد النظري ~50 MHz فقط |
| LSI يمكن أن يكون مصدر SYSCLK | ❌ مستحيل عتادياً — SW حقله 2 بت فقط |
